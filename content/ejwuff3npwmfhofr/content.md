***Studio C 4x Laserdisc + Modem*** was the original showtape format used for Studio C. Upon booting the Studio C Computer, it tries to communicate with a built-in modem. Corporate could call any store's computer through this modem to install new Showtape Data onto it to go with the new Laserdiscs that would be mailed out to stores. 
The release of the [August 1999] Showtape would also come with new DVD Players to replace the old Laserdisc Players. It's currently not confirmed if this is also when the switch to Floppy Disks for installing Showtape Data was made, or if that switch was made earlier on.
When installing the new DVD Players, 3 Players were used instead of 4, and stores were told to keep the cables for Player #4 for future use. However, these cables would never end up being used.
As of the final update for Cyberstar released with [Friday Night Neon], two commands used to communicate with the Players still try to communicate with Player #4, likely a leftover from the Laserdisc format. It's unknown if any shows use these commands.
