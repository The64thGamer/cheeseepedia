HELP!

Welcome to Cheese-E-Pedia's uh, fourth? editor? It's been the roughest part of the site since the move from Mediawiki, but after a lot of iteration and failure, this should be hopefully the easiest experience. Welcome new or returning editors!

How do I create a new page?

Simple, click this link!

What type of account do I need to edit?

You need to create an account on the Cheese-E-Pedia forums. Apologies for longtime users who were forced to make GitHub accounts before- but! you are able to create a forums account using that same GitHub account.

(As of August 16th, 2026) For new users you may notice user pages directly on the site itself with custom descriptions and images/ranking. Be aware this is being merged into the forums, soon the site will merely display and link to forum users.

What are the standards for making a page?

Best is to look to every other article. Article content consists of unique, citable information. Keep information dense- but not redundant. Cheese-E-Pedia has a parameters system that lets you log stuff like dates, remodels, stages, credits, downloads, etc. It mixes these parameters together to create a web of automated information. Keep a lot of duplicate info away from the written page unless it is important to the content/history/story the article is trying to convey.

Otherwise cite your sources, do spell checking, and use common sense! Your submitted articles aren't going to be tidied up before they go live, and if you're too sloppy they may be flatout rejected!

How do I set up article photos, videos, reviews, transcripts?

(As of September 5th, 2026) You create a new page, set the 'type' to photo/video/transcript/ect., and then set the pages you want it to appear on in the tags. Eventually there will be more streamlined buttons that let you do this straight from an article page.

Additionally, any YouTube video put as a citation will be automatically turned into a video page, just without any description or dates. If anything, please throw all relevant videos to the article in the citations (which you should be doing to be thorough anyways).

How long do submissions take?

Submissions are manually reviewed so this can generally be between a few minutes to up to a week. Be patient and try to submit your edit when it's all done and ready. Don't spam a million revisions into the system. Additionally, if you're noticing some changes are live, but not others, reset your browser cache to fully load all new changes.

Is there a way to track my submission?

No, unlike previous editors these don't go through a third party and are directly logged into the web server for manual review. If you're worried about a rejected edit, feel free to hit the Download Edits button. Post on the forums if you feel a submission was lost or was wrongly rejected.

How do I mark myself as a contributor to this page?

This is done automatically when the submission is made under your forum account. Please don't manually add yourself to the contributors list.

Why do some articles have an orange banner, and when I go to edit them the text isn't there?'

These are articles deemed unfit to edit from but still worth presenting to read. It is reccomended you start over and your submission will override the original text. If you still need a convenient way to see the original text, click the Edit Raw tab and it will be listed under old.md

I don't understand what I put in the Thumbnail text box

It wants the Title of any photo that exists on the website. This is not the filename, as all photos on the site are simply photo.avif. Everything on the site is treated like an article. You get the title by clicking on an image to show it on its own page. The title *usually* is something like 024290k23e32e.avif, but you may not see a .avif extension, or the title is just a description of the photo. Whatever the case, that yellow text is what you paste in, and if is valid should have that photo appear in the editor.
